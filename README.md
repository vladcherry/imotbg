# имоти

Карта продаж недвижимости в Софии, Пловдиве, Варне и Бургасе. Данные — с imot.bg.
Статический сайт на GitHub Pages, без бэкенда.

## Как это работает

```
GitHub Actions (cron 2×/сутки)
  └─ npm run scrape → обход imot.bg → нормализация → геокодинг по кварталам
     └─ commit public/data/*.json
GitHub Pages
  └─ SPA грузит JSON и фильтрует/сортирует всё на клиенте
```

У imot.bg нет публичного API — данные берутся парсингом HTML. Перед публичным
запуском стоит посмотреть их `robots.txt` и условия использования.

## Запуск

```bash
npm install
npm run mock   # демо-данные, чтобы интерфейс ожил сразу
npm run dev
```

## Подключение реальных данных

imot.bg хранит параметры поиска в сессионном идентификаторе `slink`.
Его нужно получить один раз руками для каждого города:

1. Открой imot.bg, настрой поиск (продажби → город → тип объекта), нажми «Търси».
2. В адресной строке будет `...act=3&slink=abc12345&f1=1`. Скопируй значение `slink`.
3. Впиши его в `scripts/config.json` для нужного города.

Дальше проверь, что парсер попадает в вёрстку:

```bash
npm run probe "https://www.imot.bg/pcgi/imot.cgi?act=3&slink=abc12345&f1=1"
```

Скрипт сохранит HTML в `scripts/.cache/probe.html` и покажет, сколько карточек
нашлось и что из них разобралось. Если ноль — открой дамп, найди блок объявления
и поправь `CARD_SELECTORS` / `FIELD` в `scripts/imotbg.mjs`. Вся привязка к вёрстке
imot.bg собрана в этом одном файле.

Когда probe даёт осмысленный результат:

```bash
npm run scrape
```

`slink` живёт ограниченное время. Если сбор начнёт возвращать пусто — обнови его.

## Координаты

imot.bg не отдаёт координаты объекта, только квартал. Точка ставится в центр
квартала из `scripts/districts.json` и детерминированно разбрасывается в радиусе
~260 м, чтобы объявления не слипались. Координаты кварталов приблизительные.

Скрапер в конце печатает список кварталов, которых нет в справочнике. Добавить:

```bash
npm run geocode sofia "Гърмидол" "Требич"
```

## Деплой

1. Запушь репозиторий на GitHub.
2. Settings → Pages → Source: **GitHub Actions**.
3. Первый пуш в `main` соберёт и опубликует сайт.

`vite.config.ts` берёт base-путь из `PAGES_BASE`; workflow подставляет туда имя
репозитория. Для домена вида `user.github.io` поставь `PAGES_BASE=/`.

Workflow `scrape.yml` коммитит свежие данные в `main`, что автоматически
запускает пересборку.

## Что внутри

| Путь | Что делает |
|---|---|
| `scripts/imotbg.mjs` | загрузка (windows-1251) и парсинг imot.bg — единственное место с селекторами |
| `scripts/scrape.mjs` | обход страниц, дедуп, геокодинг, запись JSON |
| `scripts/probe.mjs` | диагностика селекторов на живой странице |
| `scripts/mock.mjs` | генератор демо-данных |
| `src/components/PriceRibbon.tsx` | ценовая лента — распределение €/м², тянешь мышью и фильтруешь |
| `src/components/MapView.tsx` | MapLibre, кластеры, цвет точки = €/м² |

Тайлы — OpenFreeMap, без ключа и регистрации.
